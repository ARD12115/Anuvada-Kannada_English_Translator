# 5-Minute Demo Script

| Time | Step | Say |
|---|---|---|
| 0:00 | Problem | "Signs, notices and forms around us mix Kannada and English, and general translators need internet and don't read photos." |
| 0:30 | Text tab | Paste an English notice -> Kannada. "Language is auto-detected. Source stays beside the output." |
| 1:15 | Reverse | Kannada sentence -> English. |
| 1:45 | Signboard | Upload a Kannada signboard photo. "OCR reads it, we can correct it, then translate." |
| 2:30 | Notice | Paste a campus notice -> side-by-side -> download bilingual file. "Offices can publish bilingual notices in one click." |
| 3:10 | Glossary | Show HoD/CIE translated correctly vs raw output. |
| 3:40 | Offline | Turn Wi-Fi off / switch to Offline. "Open-source NLLB, nothing leaves the laptop." |
| 4:10 | Quality | "On 30 test pairs: chrF X, OCR accuracy Y%." Show the table. |
| 4:30 | Growth | "Stage 2: Kannada scam-message detection. Stage 3: Kannada document understanding with Q&A." |
| 4:50 | Close | "Machine translation, shown with its source and a disclaimer." |

## Backup
- Wi-Fi/Google down: switch to Offline (or show the automatic fallback).
- OCR fails live: show a prepared screenshot, then use the editable text box.
- Likely questions: Why not just Google Translate? How accurate is it? What about Kanglish? How is OCR handled for stylized fonts? Is any data stored?
